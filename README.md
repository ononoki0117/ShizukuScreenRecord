# Nizeo Client

`Nizeo Client`는 메타 퀘스트의 Camera API가 공식적으로 지원되기 이전, Shizuku 기반 권한을 활용해 안드로이드 기기에서 화면 캡처와 녹화를 구현한 프로젝트입니다.

이 앱은 단순한 녹화 도구가 아니라, 당시 플랫폼 제약을 우회하지 않으면서도 시스템 권한 흐름을 안전하게 활용해 캡처 파이프라인을 구성한 기술 검증 사례라는 점이 중요합니다.

현재는 Shizuku를 이용해 화면 녹화를 수행하고, 녹화 결과를 서버로 업로드한 뒤 후속 처리를 진행하는 Android 애플리케이션으로 정리되어 있습니다.

이 문서는 한국어 버전을 기준으로 작성되었으며, 일본 기업 제출 및 협업 검토를 고려해 핵심 기능, 실행 흐름, 권한 요구 사항, 그리고 프로젝트의 기술적 배경을 명확하게 정리했습니다.

## 프로젝트 배경

- 메타 퀘스트 환경에서 Camera API 지원이 제한되던 시기에 화면 캡처 경로를 확보하기 위해 개발된 프로젝트입니다.
- Shizuku를 활용해 시스템 권한 기반의 캡처 흐름을 구성했습니다.
- 단순 기능 구현보다, 당시 기술 제약 하에서 동작 가능한 실용적 우회 경로를 확보했다는 점에 의의가 있습니다.

## 주요 기능

- Shizuku 권한을 이용한 화면 녹화 실행
- 녹화 시작 전 3초 카운트다운 안내
- 녹화 시간 선택 옵션 제공 `10초 / 15초 / 20초`
- 출력 품질 선택 옵션 제공 `Low / Middle / High`
- 대상 범위 선택 옵션 제공 `ROOM / OBJECT`
- 변환 스타일 선택 옵션 제공
- 녹화 파일을 서버로 업로드하고 후속 처리 요청 수행
- 처리 완료 후 결과 URL을 브라우저로 열기

## 동작 흐름

1. 앱 실행 후 시작 화면에서 관련 안내 페이지 또는 메인 화면으로 이동합니다.
2. 메인 화면에서 녹화 범위, 길이, 품질, 스타일을 선택합니다.
3. Shizuku 권한을 확인한 뒤 녹화를 시작합니다.
4. 3초 카운트다운 후 화면 녹화를 수행합니다.
5. 녹화가 끝나면 파일을 서버로 업로드합니다.
6. 서버 처리 상태에 따라 후속 작업을 진행하고, 결과가 준비되면 브라우저로 결과 페이지를 엽니다.

## 실행 환경

- Android `8.0` 이상 `minSdk 28`
- `compileSdk 34`
- Shizuku 지원 환경
- 네트워크 연결 가능 상태

## 권한 안내

이 앱은 기능 특성상 다음 권한이 필요합니다.

- `INTERNET`
- `POST_NOTIFICATIONS` `Android 13 이상`
- `READ_EXTERNAL_STORAGE`
- `WRITE_EXTERNAL_STORAGE`
- `MANAGE_EXTERNAL_STORAGE`

또한 앱 실행 중 Shizuku 권한 허용이 필요합니다.

## 설치 및 실행

### 1. 환경 준비

- Android Studio 최신 안정 버전 설치
- Android SDK `34` 설치
- 기기 또는 에뮬레이터 준비
- Shizuku 앱 및 권한 환경 준비

### 2. 프로젝트 빌드

```bash
./gradlew assembleDebug
```

### 3. 앱 실행

- Android Studio에서 `Run`을 실행하거나
- 생성된 `debug APK`를 기기에 설치합니다.

### 4. 최초 실행 시 확인 사항

- 알림 권한 허용
- 저장소 접근 권한 허용
- Shizuku 권한 허용

## 사용 방법

1. 런처 화면에서 안내 페이지 또는 메인 화면으로 이동합니다.
2. 원하는 녹화 옵션을 선택합니다.
3. `Start Record` 버튼을 눌러 권한 확인을 진행합니다.
4. 카운트다운이 끝나면 녹화가 시작됩니다.
5. 녹화 종료 후 자동으로 업로드 및 처리 단계가 진행됩니다.

## 기술 스택

- Kotlin
- Java
- AndroidX
- Jetpack Compose
- Material Design
- OkHttp
- Shizuku API `13.1.0`

## 프로젝트 구조

- `MainActivity` - 녹화 옵션 설정 및 시작 처리
- `RecordingActivity` - 카운트다운 후 녹화 시작
- `LoadingActivity` - 업로드 및 서버 처리 대기
- `LauncherActivity` - 초기 진입 및 외부 안내 페이지 연결
- `ScreenRecorder` - 녹화 제어
- `HttpClient` - 서버 통신

## 참고 사항

- 서버 주소와 업로드 경로는 `strings.xml`에서 관리됩니다.
- 앱은 `cleartext traffic`을 허용하도록 설정되어 있습니다.
- 실제 배포 환경에서는 서버 주소, 보안 정책, 권한 정책을 재검토하는 것을 권장합니다.
